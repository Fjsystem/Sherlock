# JampaX64_Sherlock

Descarga de prueba para Android 6.0 o posterior.

- [Descargar APK para móviles actuales (ARM64)](https://raw.githubusercontent.com/Fjsystem/Sherlock/main/JampaX64_Sherlock-0.4-arm64-v8a.apk)
- [Descargar APK para modelos ARM antiguos de 32 bits](https://raw.githubusercontent.com/Fjsystem/Sherlock/main/JampaX64_Sherlock-0.4-armeabi-v7a.apk)

Versión 0.4: búsqueda con cámara, coincidencias sin distinguir mayúsculas y tildes, puntos y recuadros sobre los textos encontrados, zoom, indicador rojo/verde, pitido, vibración y parpadeo de linterna durante tres segundos.

Compilación y firmas verificadas; once comprobaciones de búsqueda y localización aprobadas. Pendiente verificar cámara y alineación de marcas en dispositivo real. APK firmados para pruebas; no son una publicación final de Google Play.

Este repositorio contiene únicamente los APK, documentación de descarga y sumas SHA-256.
