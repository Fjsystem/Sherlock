# JampaX64_Sherlock

Descarga de prueba para Android 6.0 o posterior.

- [Descargar APK para móviles actuales (ARM64)](https://raw.githubusercontent.com/Fjsystem/Sherlock/main/JampaX64_Sherlock-0.6-arm64-v8a.apk)
- [Descargar APK para modelos ARM antiguos de 32 bits](https://raw.githubusercontent.com/Fjsystem/Sherlock/main/JampaX64_Sherlock-0.6-armeabi-v7a.apk)

Versión 0.6: búsqueda con cámara, coincidencias sin distinguir mayúsculas y tildes, puntos y recuadros sobre los textos encontrados, zoom, indicador rojo/verde, pitido, vibración y parpadeo de linterna durante tres segundos.

Compilación y firmas verificadas; once comprobaciones de búsqueda y localización aprobadas. Pendiente verificar cámara y alineación de marcas en dispositivo real. APK firmados para pruebas; no son una publicación final de Google Play.

Este repositorio contiene únicamente los APK, documentación de descarga y sumas SHA-256.

La versión 0.6 incorpora un icono adaptado a partir del símbolo JampaX64 proporcionado por el usuario, con soporte de icono adaptativo de Android. Conserva la misma firma que la versión 0.4.

Versión 0.6: opción 2 (lupa) elegida para JampaX64_Sherlock. La opción 1 (ojo) se reserva para otra aplicación del usuario.
