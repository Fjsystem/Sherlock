# JampaX64: Sherlock y Eyes

Aplicaciones Android de prueba. Código y patrones privados.

## Descargas actuales

- [Eyes 0.2 (Android 64 bits)](Eyes/JampaX64_Eyes-0.2-arm64-v8a.apk)
- [Eyes 0.2 (Android 32 bits)](Eyes/JampaX64_Eyes-0.2-armeabi-v7a.apk)
- [Sherlock 0.10 (Android 64 bits)](JampaX64_Sherlock-0.10-arm64-v8a.apk)
- [Sherlock 0.10 (Android 32 bits)](JampaX64_Sherlock-0.10-armeabi-v7a.apk)

Ambas muestran el logotipo y nombre arriba, la cámara en medio y todos los controles debajo. Eyes compara toda la imagen visible y permite guardar capturas con los resultados. Al actualizar desde Eyes 0.1, captura un patrón nuevo. El indicador gris significa que todavía no se puede confirmar la comparación; prueba la aplicación con tus etiquetas reales antes de confiar en sus resultados.
